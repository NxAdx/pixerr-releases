# Pixerr BLACK KWGT - Public Beta Releases

Minimalist monochrome, pure OLED black, and brutalist bento widgets for Android.

## Direct Beta APK Download (v1.0.0-beta)

- Direct Download: https://github.com/NxAdx/pixerr-releases/releases/latest/download/pixerr-black-kwgt-v1.0.0-beta.apk

## Requirements
- [KWGT Kustom Widget Maker](https://play.google.com/store/apps/details?id=org.kustom.widget)
- **KWGT Pro Key** (required by Android / Kustom to load third-party widget packs)

## How to Test
1. Download and install the APK from the link above.
2. Long-press your Android home screen -> **Widgets** -> add an empty **KWGT** widget.
3. Tap the widget -> **Explore / Installed Packs** -> select **Pixerr BLACK KWGT**.
4. Choose any of the 25 presets. If a widget appears oversized or small on your grid, open **Layer -> Scale** inside KWGT to fit cleanly.
